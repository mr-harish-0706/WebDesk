# Security Policy & Vulnerability Reporting

WebDesk takes security and user privacy seriously. We actively implement sandbox isolation, context isolation, and session partitioning to keep web application environments secure.

---

## 🛡️ Supported Versions

| Version | Supported | Security Fixes |
| :--- | :--- | :--- |
| `1.0.x` | Yes | Active |
| `< 1.0.0` | No | End of Life |

---

## 🔒 Reporting a Vulnerability

If you discover a security vulnerability in WebDesk, please **do not open a public GitHub issue**.

Instead, send an email to our security response team:

📧 **security@webdesk.app**

### Information to Include
- Detailed description of the vulnerability.
- Proof of Concept (PoC) steps to reproduce.
- Impact on system host or session partitions.

### Response SLA
- Initial Acknowledgment: Within **24 hours**.
- Assessment & Triage: Within **72 hours**.
- Security Release: High-priority patch within **7 business days**.
