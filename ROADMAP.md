# WebDesk Product Roadmap

This document outlines the strategic feature roadmap and release milestones for **WebDesk**.

---

## 🎯 Version 1.0.0 (Current Stable)
- [x] Isolated session partition engine (`persist:profile_id`).
- [x] Linux XDG `.desktop` launcher generator in `~/.local/share/applications/`.
- [x] Custom context workspaces & profile switcher.
- [x] Quick launch command palette (`Ctrl+K`).
- [x] System tray integration & frameless window shell.
- [x] SQLite database storage service & JSON backup/restore.
- [x] Multi-format packaging (.deb, .rpm, AppImage, NSIS, DMG).

---

## 🚀 Version 1.1.0 (Q3 2026)
- [ ] Auto-Updater via `electron-updater` and GitHub Releases.
- [ ] Custom user agent switcher UI preset manager.
- [ ] Window snapping and tiling layout rules for web apps.
- [ ] Multi-monitor window position memory (`electron-window-state`).

---

## 🔌 Version 1.5.0 (Q4 2026)
- [ ] Third-party plugin marketplace API ecosystem.
- [ ] Native PWA manifest import wizard.
- [ ] Custom CSS/JS extension store per profile.
- [ ] Flatpak & Flathub official package distribution.

---

## 🌐 Version 2.0.0 (2027)
- [ ] Cross-device profile sync (End-to-End Encrypted).
- [ ] Built-in ad & tracker blocking engine (`@cliqz/adblocker-electron`).
- [ ] Global hotkey web app quick drawer.
